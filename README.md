# Financial Academy Transcripts

رونویسی، ویرایش و آماده‌سازی محتوای ویدئویی «آکادمی هوش مالی» برای استفاده در سامانه‌های بازیابی و تولید پاسخ (RAG).

وضعیت دقیق و قابل‌پردازش ماشینی در [`manifest.json`](manifest.json) نگهداری می‌شود.

## ساختار مخزن

```text
transcripts/khane-to/   متن خوانا و ویرایش‌شده هر قسمت
raw/khane-to/           خروجی خام موتور تبدیل گفتار
rag/episodes/           JSONL بخش‌بندی‌شده هر قسمت
rag/all-chunks.jsonl    خروجی تجمیعی برای ورود به RAG
scripts/                ابزار تولید و اعتبارسنجی خروجی RAG
manifest.json           مشخصات، منبع و وضعیت قسمت‌ها
```

## قالب داده برای RAG

هر خط از فایل JSONL یک قطعه مستقل است:

```json
{
  "id": "khane-to-01-001",
  "text": "...",
  "metadata": {
    "program": "خانه تو",
    "episode": 1,
    "title": "...",
    "speakers": ["دکتر کمیل رودی", "فرهاد جم"],
    "source_url": "...",
    "review_status": "reviewed"
  }
}
```

فیلد `text` برای embedding و جست‌وجوی معنایی استفاده می‌شود. `metadata` باید همراه قطعه در پایگاه برداری ذخیره شود تا پاسخ‌ها نام برنامه، قسمت و لینک منبع داشته باشند.

## تولید مجدد فایل‌های RAG

```bash
python3 scripts/build_rag.py
```

این فرمان فایل‌های Markdown تأییدشده را می‌خواند، آن‌ها را بر اساس عنوان‌های معنایی بخش‌بندی می‌کند و خروجی‌های `rag/episodes/*.jsonl` و `rag/all-chunks.jsonl` را می‌سازد.

## اصول ویرایش

- معنا و ترتیب گفت‌وگو حفظ می‌شود.
- خطاهای واضح تبدیل گفتار اصلاح می‌شوند.
- بازنویسی ادبی یا افزودن محتوای جدید انجام نمی‌شود.
- عبارت‌های غیرقابل‌تشخیص با `[نامفهوم]` مشخص می‌شوند.
- متن خام برای ردگیری و کنترل کیفیت حفظ می‌شود.
- فقط قسمت‌های دارای وضعیت `reviewed` وارد خروجی تجمیعی RAG می‌شوند.
